# Component map

## Hoofdscherm
`MainActivity` met één vaste landscape-layout.

| Zone | Component | Bron |
|---|---|---|
| Top | `SitLogo`, quest-status, noodstop | custom XML |
| Links | headline, uitleg, contextuele CTA | custom XML |
| Rechts | terminal-card met touchpads of voicechips | custom XML |
| Onder | drie segmenten en SIT-feiten | custom XML |

## Libraries
AndroidX AppCompat en Material zijn bestaande projectdependencies. Alle merkcomponenten zijn custom. Er komt geen derde UI-library bij.
